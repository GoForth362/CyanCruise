## Context

错题本数据与分页、详情接口已经存在，但当前界面把列表追加在错题解析页底部。静态 hash 路由应用可新增轻量页面状态，不需要后端改动。

## Goals / Non-Goals

**Goals:**

- 为错题本提供独立列表页和详情页。
- 让用户从错题解析的操作区直接进入错题记录。
- 复用既有分页和详情接口，保持用户隔离。

**Non-Goals:**

- 不增加删题、编辑题目或筛选功能。
- 不在解析页保留重复的过往错题列表。

## Decisions

- 新增 `postgraduate-mistake-book` 与 `postgraduate-mistake-detail` 两个内部路由；详情 ID 使用 hash 查询参数传递。
- 列表页按已有 `hasMore`/`nextOffset` 协议加载更多；列表卡片只展示科目、题干摘要和时间。
- 详情页按记录 ID 调用详情接口并渲染已保存的题目、错误答案和结构化 AI 解析。
- “错题记录”作为解析提交按钮旁的次级动作，避免增加页面顶部干扰。

## Risks / Trade-offs

- [直接打开无效详情 ID] → 显示可恢复的“记录不存在”提示和返回错题本入口。
- [列表接口暂不可用] → 保留返回解析页入口并显示局部错误，不影响当前解析功能。

## Migration Plan

1. 发布路由与前端页面。
2. 用户可从解析页进入错题本；历史区不再在解析页渲染。
3. 回滚时移除新路由和入口，错题本数据保持不变。
