## Context

通用深造记录用于多种分析结果，错题历史无法独立分页和扩展。现有错题解析服务已具备用户身份、题目请求和解析结果，适合在解析成功事务后写入专用错题本。

## Goals / Non-Goals

**Goals:**

- 按用户永久保存全部考研错题及其解析。
- 提供独立分页列表和详情读取接口。
- 前端支持浏览、分页加载与打开历史解析。

**Non-Goals:**

- 不实现图片识题、批量导入、跨用户共享或自动删除错题。
- 不迁移既有通用深造记录；旧记录继续保留。

## Decisions

- 新建 `cc_postgraduate_mistake_book` 表及对应存储契约，而非扩大通用深造记录查询范围。这样错题字段、索引和生命周期独立，避免其他深造分析混入错题本。
- 解析成功后由 `PostgraduateApplicationService` 同步保存错题本。保存失败将使本次操作返回清晰错误，确保“解析成功即已入库”的一致性。
- 列表接口以 `userId` 为边界并采用 `limit`、`offset` 分页；详情接口再次按用户和记录 ID 查询，避免越权读取。
- 复用 JDK 8、Cosmic WebAPI 与 PostgreSQL 存储模式，不引入第三方依赖。

## Risks / Trade-offs

- [旧通用记录不会自动出现在错题本] → 新错题从上线后开始独立保存，旧记录保留可追溯性。
- [题目文本可能较长] → 使用 TEXT/JSON 文本字段，并在列表仅返回摘要。
- [频繁翻页] → 按用户和更新时间建立索引，前端按需加载。

## Migration Plan

1. 部署时使用 `CREATE TABLE IF NOT EXISTS` 创建错题本表与索引。
2. 发布 WebAPI 和前端后，新解析自动写入专表。
3. 若需回滚，停止调用新接口；表和历史数据保持不删除。
